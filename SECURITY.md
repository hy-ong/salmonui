# Security Policy

## Supported versions

Security fixes are released for the latest published version of the
`@salmonui/*` packages. All packages are released together with one version
number.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting:
open the repository's **Security** tab and choose **Report a vulnerability**
(https://github.com/hy-ong/salmonui/security/advisories/new).

Please include:

- the affected package(s) and version(s),
- a description of the issue and its impact,
- steps or a minimal example to reproduce it,
- any known mitigation.

You should receive an acknowledgement within a few days. We will keep you
informed while we investigate and fix the issue, and credit you in the
advisory unless you prefer otherwise. Please give us a reasonable time to
release a fix before disclosing the issue publicly.
