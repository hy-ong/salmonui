---
title: Adaptive UI
description: Adaptive mode as a container query on the grid's own width, vertical card rows over the same virtualized row window, full-screen sort, filter, column chooser and edit sheets, bottom-sheet menus, touch long-press, native swipe scrolling and the multi-select toggle, and 44 px targets.
---

Narrow the frame below 640 px (or pick `both`) to switch to the adaptive
layout. With `defaultActive` the server renders the cards too, so the page
hydrates without a layout switch.

Double-click a record (double-tap on a phone), or select one and use **Edit**,
to edit it in a full-screen sheet with a labelled close button; **Add** opens
the same sheet for a new record. The cards stay virtualized while you edit.
