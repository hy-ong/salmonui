---
title: Select multiple
description: MultiSelect CheckBox mode with select all and group selection, a selection limit with a custom separator, and a count summary over 10,000 items.
category: dropdowns
---

Space toggles the active option and the popup stays open; Ctrl+A (Cmd+A)
selects every option, or clears them when all are selected. The third Select windows its 10,000 options.
