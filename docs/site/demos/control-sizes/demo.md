---
title: Control sizes
description: Select, Combobox, TreeSelect, DatePicker and TimePicker at the sm, md and lg sizes, 24, 32 and 40 pixels tall, next to a Button of the same size.
category: dropdowns
---

Each row sets one `size` on every control. Heights, inline padding and icon
sizes match the Button of the same size, so a row of mixed controls lines
up. The popups keep one size.
