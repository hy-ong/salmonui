---
title: Tree View basics
description: A file tree with reactive expanded and selected ids, multiple selection with Ctrl/Cmd and Shift, a disabled folder and the APG keyboard model.
category: navigation
---

Click a row, Ctrl/Cmd+click and Shift+click to select; use the arrow keys,
Home/End, `*` and typeahead. The **secrets** folder is disabled: it is
focusable but cannot be selected or expanded.
