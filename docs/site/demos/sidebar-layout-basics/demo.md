---
title: Sidebar layout basics
description: A push-mode SidebarLayout with a navigation panel, an icon rail toggle, a cancellable close and a container breakpoint that switches to the overlay presentation.
category: navigation
---

Toggle the panel with the menu button, shrink it to an icon rail with the
second button, and tick **Keep open** to cancel closing in
`onBeforeOpenChange`. Below 640 px of layout width the panel switches to the
overlay presentation and starts closed.
