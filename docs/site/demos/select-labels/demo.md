---
title: Select and Combobox labels
description: A Select and a Combobox labelled, described and marked invalid through their own label, description and errorMessage props, without a wrapping Field or a hand-written label element.
category: dropdowns
---

Open and close Status without choosing to see the error. The label names
the control through `aria-labelledby`, the description and the visible
error are in its `aria-describedby`, and pressing the label focuses the
control.
