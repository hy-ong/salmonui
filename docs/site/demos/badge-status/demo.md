---
title: Status badges
description: Inline status labels with variant="dot" in every tone, in running text and in a table column, where the decorative dot carries the tone and the text carries the meaning.
category: notifications
---

The dot is an empty pseudo-element in the tone color, so screen readers
read only the text ("Paid"); the text keeps the surrounding color and
font. The dot sits at the inline start, so it moves to the right under
`dir="rtl"`.
