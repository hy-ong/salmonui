---
title: Calendar with week numbers and today button
description: An inline Calendar with single selection, ISO week-number row headers, the today button and the view and focused-date callbacks.
category: calendars
---

Click the month heading to move up to the year and decade views; arrow
keys, Home / End, PageUp / PageDown and Ctrl+Up / Ctrl+Down work in every
view. Today is highlighted only after hydration, so the server markup never
depends on the server's clock.
