---
title: Tree checkbox cascade
description: Checkboxes in the tree column whose state is the row selection, with self, hierarchy and filtered hierarchy cascade modes and tri-state parents.
---

Check a folder to select its subtree as one range update; a partly checked
folder shows the mixed state. Collapsing a folder never deselects its rows.
With the filtered mode, filter the Name column first: the cascade reaches
only the rows the filter keeps.
