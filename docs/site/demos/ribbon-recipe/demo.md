---
title: Ribbon
description: Tabs whose panels each hold a Toolbar of labelled groups with multi-size commands, a group launcher, a File menu, a contextual tab, the simplified layout and a collapsed ribbon in a Popover.
category: navigation
---

Narrow the ribbon with the slider: **Find** steps down first, then **Copy**
and **Cut**, then **Paste** (the highest `overflowPriority`); only when every
command is at its small size do items move into the "more" menu, listed
under their group label. **Simplified** switches every command to its small
size; **Collapse** hides the panels and shows the selected tab's commands in a
Popover on a tab click. Tick "A table is selected" for the contextual
**Table Design** tab.
