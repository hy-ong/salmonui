title: Custom format patterns
description: Number patterns (`#,##0.00`, `0.0##`, quoted literals, `%`, zero padding), date patterns with quoted text, a skeleton object, and `formatValue` in a cell template, switched between locales.

Each header shows the column `format`. Switch the locale: patterns keep their
digits and literals while the grouping and decimal separators, month and
weekday names follow the locale.
