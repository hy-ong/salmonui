---
title: Sidebar menu on a dark surface
description: An admin sidebar with three groups, two nested submenus and every submenu open, colored by the sidebar surface variables for a dark sider.
category: navigation
---

The menu reads the theme's sidebar surface variables
(`--salmon-surface-sidebar-bg`, `-fg`, `-hover`, `-selected-bg`,
`-selected-fg`, `-border`). Here they are set on the panel itself; in an
app, set them once in the theme and every sidebar menu, flyout and tooltip
follows. Without them the menu uses the neutral theme colors. Collapse the
rail to see the flyouts take the same dark surface.
