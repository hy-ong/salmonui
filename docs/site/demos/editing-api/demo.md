title: Edit methods and events
description: The editing capability flags, newRowPosition, tabToNextRow, read-only columns and isCellEditable, every edit method on the Data Grid instance and every edit event in a log.
---

Switch `edit`, `add` and `delete` off to see the matching keys, toolbar
items and methods refuse. The method buttons call the Data Grid instance; every
before-event and after-event lands in the log, and the last checkbox cancels
`onBeforeEditStart` on the first row.
