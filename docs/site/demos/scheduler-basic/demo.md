---
title: Scheduler
description: A week calendar in Europe/Berlin with a recurring standup, overlapping events, an all-day offsite and a blocked lunch; create, edit and delete events.
category: calendars
---

Click a time slot to add an event with a title, double click an event to
edit it in the dialog, and switch views in the header. Editing an
occurrence of the standup asks whether to change one event, the following
ones or the whole series.
