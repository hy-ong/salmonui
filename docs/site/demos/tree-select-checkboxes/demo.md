---
title: TreeSelect checkboxes
description: Multiple TreeSelect with tri-state checkboxes, cascade or independent checks, Select all, and the text, chips and count value displays.
category: dropdowns
---

Check **Fruit**: its children follow and it reads as checked; uncheck one
child and Fruit turns mixed. Switch **Checks** to independent to check a
parent alone. Switch the value display between text, chips (they wrap onto
more lines) and a count. Ctrl+A (Cmd+A) toggles every node.
