---
title: Image editor
description: A Canvas 2D image editor with crop, rotate, flip, straighten, resize, zoom, finetune, filter presets, frames, shape, text and freehand annotations, redaction, undo and export.
category: editors
---

The picture is generated in the browser. Pick a tool from the toolbar: Crop
shows ratio presets and handles, Finetune and Filter preview while you drag,
the shape tools draw on drag (a click places a default size). Click an
annotation to move, resize or rotate it; its quick-access toolbar duplicates,
deletes and reorders it. The licence plate is a pixelate redaction that is
burned into the exported pixels. Ctrl+Z undoes; Ctrl+wheel zooms.
