---
title: Floating action button
description: Floating buttons positioned by CSS inside a panel, with pickers for the nine logical positions, tone and variant, a visibility toggle, custom insets and a press-and-hold floating button.
category: buttons
---

**Compose** is an icon-only floating button named by `aria-label` (with a
`title` tooltip): circular and elevated by the system CSS, `tone="primary"`
by default, and activated by Enter or Space like any button. **Visible** sets
the native `hidden` attribute, **Extra inset** sets its own edges' logical
`style` insets to 48 px (from the default 16 px), and the tone and variant pickers
restyle it. **Zoom in** is a floating button with a text label and `repeat`:
hold it to keep zooming.
