---
title: Dashboard Layout
description: A resizable analytics dashboard driven by a controlled layout, with panels added and removed at run time, a pinned static panel, vertical compaction, keyboard moves and stacking below 560 px.
category: layout
---

Drag a panel by its header, or resize it from the bottom-end corner. Focus
a panel and press Enter to pick it up, then use the arrow keys (Shift to
resize), Enter to drop and Escape to cancel. Narrow the window below
560 px to stack the panels.

Add panel, Remove last panel and Reset layout change the controlled
`layout` array; the panels are
rendered from it.
