---
title: Block Editor
description: A controlled BlockEditor with checklists, a callout, nested lists, code, mentions and labels; the block JSON and the block events update as you edit.
category: editors
---

Type `/` at the start of a block for the slash menu, select text for the
formatting toolbar, and hover a block for its drag handle: click it for
duplicate, delete, move and turn into, or drag it to reorder. `@` inserts a
mention, `#` a label. Markdown shortcuts work as you type (`# `, `- `,
`1. `, `[] `). Ctrl+Shift+Arrow (Cmd+Shift+Arrow) moves the current block,
Alt+F10 opens its menu from the keyboard.
