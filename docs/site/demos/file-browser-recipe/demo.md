---
title: File browser
description: A file browser composed from TreeView, Breadcrumbs, Toolbar, DataGrid, ContextMenu, FileUpload, Dialog and Splitter over an application file API.
category: navigation
---

Pick a folder in the tree or the address bar, double-click a folder row to
open it, right-click a row for the context menu, and use the toolbar to
create, rename, delete or upload. **Icons** swaps the details grid for
a card grid. The "server" is an in-memory store with async calls, standing in
for your own file API.
