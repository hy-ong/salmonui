---
title: Tree View with 100,000 items
description: A virtualized tree of 100,010 nodes with checkboxes and multiple selection; expandAll, collapseAll and focusItem through the ref API.
category: navigation
---

Only the rows in view are rendered. **Expand all** flattens every item in
one pass; **Go to** expands the ancestors, scrolls the virtual list and moves
focus to the item.
