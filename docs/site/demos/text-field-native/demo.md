---
title: Native text attributes
description: TextField and TextArea pass native attributes through - autoComplete tokens, maxLength with a live counter, and a multi-line TextArea sized with rows and cols.
category: inputs
---

Focus the email and password fields to see the browser's autofill for the
`autoComplete` token (the search field turns it off). Type past the
tagline's 40 characters or the bio's 160: the native `maxLength` stops the
input and the description counts the characters. The bio is a `TextArea`,
the multi-line TextBox, sized with `rows` and `cols`.
