description: 2,000 rows by 81 columns under stacked headers with column virtualization on; resize, reorder, autofit, grouping from the column menu, batch editing, the fill handle, detail rows, copy and print reach columns that were never rendered.

Only about ten of the 80 center columns are in the DOM at a time. The buttons
act on columns outside the rendered window: autofit every column, copy a range
over all 80 columns, or open the column menu of column 75 and group by it.
