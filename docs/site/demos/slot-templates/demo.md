---
title: Filter, pager and empty templates
description: A column `renderFilter` in the filter menu, a `renderPager` pager and a `renderEmpty` message for "no data" and "no match", all defined once at module scope.
---

Open the Category column's filter menu to use the custom filter editor, page
with the custom pager, and search for text that matches nothing (or tick "No
data") to see the empty template.
