---
title: Select basics
description: A controlled Select with a clear button, a searchable Select with accent folding and highlighted matches, and a required form field.
category: dropdowns
---

Open with a click, Arrow keys or Space; type letters on the closed Select to
pick an option. The searchable Select moves focus into its search field;
Escape clears the search, then closes. Submitting the empty form shows the
browser's own required message.
