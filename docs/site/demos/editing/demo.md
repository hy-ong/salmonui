---
title: Editing
description: Inline row, batch, dialog and cell editing with the built-in editors, a command column, validation messages, edit marks, confirm prompts, the unsaved-changes guard and undo.
---

Pick a mode, then double click a cell, press F2, or use the command
buttons. Insert adds a row, Delete removes the selected rows, Enter saves,
Escape cancels, and Ctrl+Z / Ctrl+Y undo and redo edits. In batch mode the
changes stay marked until Save; the toolbar Save asks first (`confirmSave`),
Cancel asks before it discards (`confirmDiscard`), and sorting with unsaved
changes asks before it discards them. The toolbar edit items enable and
disable with the edit state.
