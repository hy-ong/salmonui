---
title: Column menu
description: The header menu with every built-in item (sort, clear sort, filter, group, auto-size, pin, column chooser) in a custom order, a checkbox item and a submenu, per-column items through `onBeforeColumnMenuOpen`, `column.menu: false`, and `onColumnMenuItemClick`.
---

Focus a header and press Shift+Alt+ArrowDown to open its menu; Escape
closes it and returns focus to the header. The Order column has no menu.
