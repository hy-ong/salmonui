title: Gantt export, keyboard and languages
description: Excel, CSV and vector PDF export through lazily loaded writers, print, the default context menu, the keyboard model and labelled taskbars, German strings, Arabic right to left, the adaptive one-pane layout and the task lookup methods.
category: calendars
---

The export buttons (and the toolbar items) write the task pane as XLSX or
CSV, and both panes as a landscape A4 PDF fitted to the page width, with a
header and footer. Right-click a grid row or a taskbar for the context
menu: task information, add above, below or as a child, a milestone,
indent, outdent, delete and the Data Grid items. Click a row and use the
keyboard: the grid keys move between cells, F6 moves focus to the chart,
where Up / Down select tasks, Left / Right scroll, Enter opens the dialog
and Ctrl+Plus / Ctrl+Minus zoom; Alt+Shift+Right / Left indent and outdent.
Each taskbar is labelled with its name, dates and progress for screen
readers. Switch to Deutsch for the German date names and pane labels, or
to Arabic: the timeline runs right to left. Tick "Narrow container": below
640 px the Gantt shows one pane at a time with a Tasks / Timeline switch.
The last button reads a task and its computed information.
